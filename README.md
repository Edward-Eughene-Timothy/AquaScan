I've reviewed the repository thoroughly. **AquaScan** is a microplastic detection system with:

- Python tooling for building/validating a YOLO dataset of 6 microplastic classes (ABS, Nylon, PE, PET, PS, PVC)
- Training scripts for YOLOv8n, YOLO11n, and YOLO26n
- An Android app (`com.mirai.microplasticdetector`) built with Jetpack Compose, CameraX, ONNX Runtime, and Room that runs on-device inference using `best.onnx`

```markdown
# AquaScan

**AI-powered Microplastic Detection System**

AquaScan is an end-to-end solution for detecting and classifying common microplastics using computer vision. It includes a full dataset preparation & training pipeline and a production-ready Android application that performs real-time on-device inference.

---

## Features

### Machine Learning Pipeline
- Dataset cleaning & validation scripts
- Stratified train/val/test split generation (70/20/10)
- Training support for multiple YOLO models:
  - YOLOv8n
  - YOLO11n
  - YOLO26n
- Visualization of annotations

### Android Application
- Real-time camera-based detection using **ONNX Runtime**
- Clean modern UI built with **Jetpack Compose**
- CameraX integration
- Local history storage with **Room** database
- Detects 6 microplastic types:
  - **ABS**
  - **Nylon**
  - **PE** (Polyethylene)
  - **PET** (Polyethylene Terephthalate)
  - **PS** (Polystyrene)
  - **PVC** (Polyvinyl Chloride)

## Getting Started

### 1. Python Environment (Dataset & Training)

```bash
# Create and activate virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # Linux/macOS
# or
venv\Scripts\activate           # Windows

# Install dependencies
pip install -r requirements.txt
```

> Current dependency: `ultralytics==8.4.129`

### 2. Dataset Preparation

The scripts expect the following local directory structure (not included in the repo):

```
~/Microplastic_Project/
├── dataset_raw/dataset_microplastic-main/   # Raw image ZIPs
├── annotation_raw/Alldataset_annotation/    # YOLO .txt annotations
└── dataset_work/                            # Generated by build_dataset.py
```

Run the pipeline in order:

```bash
# 1. Validate raw data
python validate_dataset.py

# 2. Build clean dataset
python build_dataset.py

# 3. Create YOLO splits
python create_yolo_split.py

# 4. (Optional) Visualize annotations
python visualize_annotations.py
```

### 3. Training Models

```bash
# Train a single model
python training/train_yolo11n.py --epochs 50 --imgsz 640 --batch 8 --device 0

# Or train all models sequentially
python training/train_all.py
```

Trained models are saved under `runs/`.

### 4. Android Application

1. Open the project in **Android Studio**:
   ```
   mobile/android/
   ```
2. The ONNX model is already included at:
   ```
   mobile/android/app/src/main/assets/best.onnx
   ```
3. Build & run on a device or emulator (minSdk 26).

**Permissions required:** Camera
